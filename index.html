STEP ③ · CLAUDE CODE 설치

관리자 권한 없이, 한 줄이면 끝납니다

irm https://claude.ai/install.ps1 | iex
Windows PowerShell
PS C:\Users\hong> irm https://claude.ai/install.ps1 | iex Downloading Claude Code … Installing to C:\Users\hong\.local\bin … Claude Code 설치 완료 Run 'claude' to get started

화면 예시 · 버전에 따라 문구가 다름

  • Node.js는 설치하지 않아도 됩니다. Claude Code는 자체 실행 프로그램이라 별도 런타임 없이 동작합니다.
  • 설치 위치는 C:\Users\사용자명\.local\bin — 내 계정 폴더 안이라 관리자 권한이 필요 없습니다.
  • 이후 업데이트는 백그라운드에서 자동으로 이뤄집니다. 다시 설치할 필요가 없습니다.
  • irm이 인식되지 않는다는 오류가 나면 지금 창이 CMD입니다. PowerShell을 열어 다시 실행하세요.

STEP ④ · 반드시 거쳐야 하는 단계

설치 직후에는 claude 명령을 못 찾습니다 — 창을 껐다 켜세요

왜 그런가

  • 설치 프로그램이 claude의 위치를 Windows에 새로 등록합니다.
  • 그런데 지금 열려 있는 PowerShell 창은 열릴 때의 정보를 그대로 들고 있어서, 방금 등록된 위치를 모릅니다.
  • 그래서 새 창을 열어야 갱신된 위치를 읽습니다. 설치가 잘못된 게 아닙니다.

할 일

1지금 창을 X로 완전히 닫는다
2Win + X → 터미널로 새로 연다
3새 창에서 다음 장의 확인을 진행한다
Windows PowerShell
PS C:\Users\hong> claude --version claude : 'claude' 용어가 cmdlet, 함수, 스크립트 파일 또는 실행할 수 있는 프로그램 이름으로 인식되지 않습니다. → 이 메시지가 보이면 십중팔구 이 단계를 건너뛴 것입니다. 창을 닫고 새로 여세요.

화면 예시 · 버전에 따라 문구가 다름

  • 설치 위치는 ~/.local/bin — 내 홈 폴더 안이라 관리자 권한이 필요 없습니다. 앞에 sudo 를 붙이지 마세요. 파일 주인이 관리자로 바뀌어 나중에 자동 업데이트가 실패합니다.

  • Homebrew를 이미 쓰고 있다면 brew install --cask claude-code 도 됩니다. 다만 이 방식은 자동 업데이트가 안 되므로, 처음이라면 위 명령을 권합니다.
